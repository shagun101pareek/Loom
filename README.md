# Portfolio

Next.js portfolio environment: TypeScript, Tailwind, GSAP, Lenis, Motion, React Three Fiber, and MDX.

## Scripts

```bash
npm run dev
npm run build
npm run lint
```

Open [http://localhost:3000](http://localhost:3000).

## Where things live

- `src/app` — routes
- `src/components/smooth-scroll.tsx` — Lenis synced to GSAP ScrollTrigger
- `src/components/scene.tsx` — client-side React Three Fiber canvas
- `src/content/projects` — MDX case studies
- `src/mdx-components.tsx` — shared MDX element styles
